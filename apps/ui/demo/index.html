This is the real app, not a mockup — the same Svelte components, the same tokens, the same CSS that will run on the Pi. Skip a track and watch the accent follow the album a beat later — the delay is real, not an affectation: extraction needs the image, and the image needs a decode.

Visual opens the theme list.
